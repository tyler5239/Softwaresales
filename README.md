# Project Name — Software Company Website

Responsive, static marketing website for a developing budget and labor-hour cost software company.

## Files
- `index.html` — all website sections and content
- `styles.css` — responsive dark enterprise design
- `script.js` — mobile navigation and email inquiry form

## Run locally
Open `index.html` in a browser. No build tools or dependencies required.

## Before publishing
1. Replace **Project Name / PROJECTNAME** with the selected company name.
2. In `script.js`, replace `const CONTACT_EMAIL=''` with a real inbox (e.g., `const CONTACT_EMAIL='sales@example.com'`). Until then, the inquiry form intentionally does not send or open an email.
3. Verify the product description and features against the actual software. The dashboard is explicitly illustrative, not a screenshot.
4. Confirm subscription price, licensing scope, terms, and any device limits before accepting payments.
5. Add a privacy policy and any other legal notices appropriate for the actual deployment. The current form does not transmit to a server.

## Publish with GitHub Pages
Create a repository, upload the three website files to its root, and enable GitHub Pages in repository Settings → Pages → Deploy from a branch (main / root). The site uses relative asset paths and works on project Pages URLs.

## Notes
No payment gateway, license verification, backend, database, analytics, or live form submission is included. The $100/month price is labeled proposed. No testimonials or unverified product performance claims are included.
